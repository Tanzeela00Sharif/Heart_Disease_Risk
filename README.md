# Heart-Disease-Prediction-Web-App
# ❤️ Heart Disease Prediction Web App

An AI-powered web application that predicts a patient's heart disease risk from 13 clinical parameters, using a machine learning model trained in Python. Built with Flask, containerized with Docker, and deployed live on Azure Container Apps. Includes both a full web interface and a REST API for programmatic access.

**🔗 Live Demo:** https://heart-disease-app.icysand-86d71c21.westus2.azurecontainerapps.io/

## ✨ Features

- **AI-powered prediction** — trained scikit-learn classification model estimates heart disease risk from patient data
- **Clean, modern UI** — 3-page flow (landing → form → result) with a healthcare-focused design, responsive across desktop/tablet/mobile
- **REST API** — a `/api/predict` JSON endpoint so other apps/services can integrate with the model directly, not just the web form
- **Input validation** — both client-side and server-side, with clear error messages instead of raw crashes
- **Production-hardened backend** — health check endpoint, structured logging, safe error handlers, CORS support
- **Containerized & cloud-deployed** — packaged with Docker and running on Azure Container Apps, scaling to zero when idle

## 🚀 Getting Started Locally

### Prerequisites
- Python 3.11+
- pip

### Setup

```bash
git clone https://github.com/<your-username>/<your-repo-name>.git
cd <your-repo-name>

python -m venv venv
venv\Scripts\activate        # Windows
source venv/bin/activate     # Mac/Linux

pip install -r requirements.txt
python app.py
```

Visit `http://127.0.0.1:5000` in your browser.

### Run with Docker instead

```bash
docker build -t heart-disease-app .
docker run -p 8080:8080 heart-disease-app
```

Visit `http://localhost:8080`.

## 📡 REST API

### `POST /api/predict`

Send patient data as JSON and receive a prediction back — useful for integrating this model into other apps, scripts, or services without using the web form.

**Request:**
```bash
curl -X POST https://heart-disease-app.icysand-86d71c21.westus2.azurecontainerapps.io/api/predict \
  -H "Content-Type: application/json" \
  -d '{
    "Age": 45,
    "Gender": 1,
    "Chest_Pain_Type": 0,
    "Resting_Blood_Pressure": 120,
    "Cholesterol_Level": 200,
    "Fasting_Blood_Sugar": 0,
    "Resting_ECG_Result": 0,
    "Max_Heart_Rate": 150,
    "Exercise_Induced_Angina": 0,
    "ST_Depression": 1.0,
    "ST_Slope": 0,
    "Major_Vessels": 0,
    "Thalassemia": 0
  }'
```

**Response:**
```json
{
  "prediction": 0,
  "risk": "low",
  "confidence_percent": 12.4
}
```

### `GET /health`

Simple health check used by the deployment platform.

```json
{"status": "ok"}
```

## 🧠 Model Details

The model was trained on the UCI Heart Disease dataset (or *update this line with your actual dataset source*) using scikit-learn in Google Colab. It takes 13 clinical features as input:

`Age`, `Gender`, `Chest_Pain_Type`, `Resting_Blood_Pressure`, `Cholesterol_Level`, `Fasting_Blood_Sugar`, `Resting_ECG_Result`, `Max_Heart_Rate`, `Exercise_Induced_Angina`, `ST_Depression`, `ST_Slope`, `Major_Vessels`, `Thalassemia`
